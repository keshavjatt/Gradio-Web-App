# 🚀 Multi-Task Gradio Web App

A comprehensive AI application with multiple NLP and Computer Vision tasks in a single interface.

## Features

- 😊 Sentiment Analysis
- 📝 Text Summarization  
- 🔮 Next Word Prediction
- 🌐 Translation (English to French)
- 🏷️ Named Entity Recognition
- 🎨 Image Generation

## 🧾 How to Run this Project

```bash
git clone https://github.com/keshavjatt/SmartPremium-Insurance.git
cd Gradio-Web-App
pip install -r requirements.txt
python app.py
