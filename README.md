# 🚀 Multi-Task Gradio Web App

A comprehensive AI application with multiple NLP and Computer Vision tasks in a single unified interface. This project demonstrates the integration of six different machine learning models into one user-friendly web application using Gradio, optimized specifically for CPU deployment.

## Features

- Analyze text for positive, negative, or neutral sentiment
- Real-time confidence scoring
- Adjustable summary length
- Predict the most likely next words in a sentence
- Multiple prediction options with probabilities
- Powered by Helsinki-NLP's translation model
